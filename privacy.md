# Syndicate Games Privacy Policy

Effective Date: July 3, 2026

Syndicate Games is committed to protecting user privacy and complying with Discord’s Developer Policies. This document explains what data we collect, why it is required for bot functionality, how we secure it, and how users can request deletion.

---------------------------------------------------------------------

1. What Data We Collect

We only collect the minimum data necessary to operate Syndicate Games features:

- Discord Identifiers: Discord User IDs and Guild/Server IDs used to associate game profiles with the correct user and server.
- Gameplay Data: Scores, inventories, statistics, and economy values tied to your User ID.
- Command Inputs: Content explicitly submitted through bot commands to process gameplay actions.
- Real-Time Message Scanning: Certain moderation and automation features (our anti-abuse “Ping Shield” system and admin-configured keyword “Triggers”) read ordinary message text in real time to determine whether a rule applies. This content is processed transiently and is never written to our database — if a rule fires, only a short preview may appear in a staff-configured log channel within Discord itself.

We do not collect or store full message history or private messages.

---------------------------------------------------------------------

2. Why We Collect This Data

We use this information exclusively for the following operational purposes:

- Core Game Functionality: Saving progress, maintaining leaderboards, and syncing game states across servers.
- Anti-Cheat & Integrity: Detecting exploit attempts, duplicate accounts, or automated abuse.
- Security & Diagnostics: Identifying bugs, resolving errors, and ensuring stable bot performance.

We never sell, rent, or share user data with third parties.

---------------------------------------------------------------------

3. How to Request Data Deletion

Users maintain full control over their data. To request deletion of all information associated with your Discord ID, use one of the following methods:

- Support Server: Contact our support team through our official Support Server: https://discord.gg/Hj6jWYTwKG
- Developer Email: Email our team at Troublethedonsyndicate@gmail.com

Once a request is received, all game profiles, progress, and stored data linked to your Discord ID will be permanently removed from active databases within 48 hours.

---------------------------------------------------------------------

4. Data Security & Storage

We follow industry-standard security practices to protect user information:

- Access Control: Only authorized developers can access operational databases.
- Data Minimization: We store only what is required for gameplay functionality.
- Secure Storage: All data is stored in protected environments with restricted access.
- No Long-Term Retention: Data is removed when no longer needed or upon user request.
